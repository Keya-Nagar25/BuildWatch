# BuildWatch
BuildWatch turns your phone into an offline-capable CI/CD triage assistant. When a GitHub Actions build fails, the log is pushed to your phone and an on-device model — running entirely on the Snapdragon NPU, no cloud call — diagnoses the failure type and suggests a fix in seconds, even with zero connectivity. One tap hands that context to your laptop via Office Kit, so you land at your IDE already knowing what's wrong. Built for developers and small teams who lose 10-20 minutes per failure just re-reading the same stack trace — BuildWatch collapses that dead time into a 5-second phone glance.
